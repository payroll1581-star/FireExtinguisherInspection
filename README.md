# 🧯 ระบบตรวจเช็คถังดับเพลิงออนไลน์ (Smart Fire Extinguisher Inspection System)

Web App บน Google Apps Script + Google Sheets สำหรับสแกน QR Code ตรวจถังดับเพลิงด้วยสมาร์ทโฟน บันทึกผลอัตโนมัติ ดู Dashboard แบบเกือบ real-time และแจ้งเตือนถังชำรุด/หมดอายุทางอีเมล

---

## ติดตั้ง (คัดลอกวางใน Apps Script Editor) — ประมาณ 15 นาที

### 1) สร้าง Google Sheet และสคริปต์
1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น `ระบบตรวจถังดับเพลิง`
2. เมนู **Extensions → Apps Script** (ส่วนขยาย → Apps Script)
3. เปิดไฟล์ `appsscript.json` ใน Editor:
   **Project Settings (⚙️) → ติ๊ก "Show "appsscript.json" manifest file in editor"** แล้วกลับไปที่ Editor วางเนื้อหาจากไฟล์ `appsscript.json` ทับ
4. สร้างไฟล์ Script (ปุ่ม **＋ → Script**) ตามชื่อด้านล่าง แล้ววางโค้ดให้ตรงไฟล์ (Editor จะเติม `.gs` ให้เอง)
   `Code`, `Auth`, `Api`, `Notify`, `Report`, `Setup`, `Tests`
   (ไฟล์ `Code.gs` เดิมที่มีอยู่ ให้ลบเนื้อหาเดิมแล้ววางทับ)
5. สร้างไฟล์ HTML (ปุ่ม **＋ → HTML**) ชื่อ `Index`, `Styles`, `App`, `I18n`, `Print` แล้ววางโค้ดให้ตรงไฟล์ — **ชื่อต้องตรงตัวพิมพ์เล็ก/ใหญ่**
6. กด 💾 Save

### 2) ติดตั้งระบบ
1. ใน Editor เลือกฟังก์ชัน `setup` แล้วกด **Run**
2. ระบบจะขอสิทธิ์ (Sheets, Drive, Docs, Gmail ส่งอีเมล, Triggers) → **Review permissions → เลือกบัญชี → Advanced → Go to … (unsafe) → Allow**
   (คำเตือน "unsafe" แสดงเพราะเป็นสคริปต์ที่คุณเขียนเอง ยังไม่ผ่านการรับรองจาก Google)
3. กลับไปที่ Google Sheet แล้วรีเฟรช จะมีเมนู **🧯 ระบบถังดับเพลิง**
   (ครั้งต่อไปกด **⚙️ ติดตั้งระบบ** จากเมนูนี้ได้เลย ปลอดภัยที่จะกดซ้ำ ข้อมูลเดิมไม่หาย)

`setup()` จะสร้างให้:
- ชีต **Equipment** (ข้อมูลถัง), **Inspections** (ประวัติ — ล็อกไม่ให้แก้ด้วยมือ), **Users** (ซ่อน + ล็อก), **Config**, **Checklist**
- โฟลเดอร์ Drive `ระบบตรวจถังดับเพลิง (ไฟล์ระบบ)` → `รูปถังชำรุด`, `รายงานประจำเดือน`
- Trigger: สรุปรายวัน (ตามชั่วโมงใน Config, ค่าเริ่มต้น 08:00–09:00 น.) และรายงานวันที่ 1 ของทุกเดือน (07:00–08:00 น.)
- Secret สำหรับ token และ PIN pepper ใน Script Properties

### 3) ตั้งค่าในชีต Config
| Key | ใส่อะไร |
|---|---|
| `ORG_NAME` | ชื่อหน่วยงาน |
| `EXPIRY_WARN_DAYS` | เตือนใกล้หมดอายุกี่วัน (ค่าเริ่มต้น 30) |
| `ALERT_EMAILS` | อีเมลผู้รับแจ้งเตือน/รายงาน คั่นด้วย `,` |
| `DAILY_ALERT_HOUR` | ชั่วโมงส่งสรุปรายวัน (แก้แล้วกด **ติดตั้งระบบ** ซ้ำ) |
| `WEBAPP_URL` | URL ของ Web App ที่ลงท้าย `/exec` (ได้จากข้อ 5) |
| `SCANNER_URL` | (ไม่บังคับ) URL หน้าสแกนกล้องสดบน GitHub Pages เช่น `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/` — ดูหัวข้อ "สแกนกล้องสดบนมือถือ" |

### 4) เพิ่มผู้ใช้
เมนู **🧯 → 👤 เพิ่มผู้ใช้** → ใส่ชื่อ → เลือก Admin/Inspector → ตั้ง PIN 4–6 หลัก (แนะนำ 6 หลัก)
- ต้องมี **Admin อย่างน้อย 1 คน**
- ลืม PIN / ถูกล็อก → **🔑 ตั้ง PIN ใหม่ / ปลดล็อก** (session เดิมของคนนั้นจะถูกยกเลิกทันที)
- ปิดการใช้งานผู้ใช้: ยกเลิกการซ่อนชีต Users แล้วเอาติ๊ก "ใช้งานอยู่" ออก

### 5) Deploy เป็น Web App
1. Apps Script Editor → **Deploy → New deployment → ⚙️ Select type → Web app**
2. **Execute as: Me** · **Who has access: Anyone**
3. กด **Deploy** → คัดลอก **Web app URL** (ลงท้าย `/exec`) → วางใน Config → `WEBAPP_URL`
4. แก้โค้ดภายหลัง: **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** (URL เดิมไม่เปลี่ยน ป้าย QR ที่พิมพ์แล้วใช้ต่อได้)

> ⚠️ อย่าใช้ URL ที่ลงท้าย `/dev` ในป้าย QR — ใช้ได้เฉพาะเจ้าของสคริปต์

### 6) ใส่ข้อมูลถังในชีต Equipment
| คอลัมน์ | ตัวอย่าง | หมายเหตุ |
|---|---|---|
| รหัส | `FE-001` | ไม่ซ้ำ ใช้ A–Z, 0–9, `-`, `_` |
| อาคาร / ชั้น / จุดติดตั้ง | `อาคาร A` / `2` / `หน้าห้องไฟฟ้า` | |
| ชนิด | `ผงเคมีแห้ง ABC` | เลือกจาก dropdown |
| ขนาด (ปอนด์) | `15` | |
| ยี่ห้อ | | |
| วันที่ติดตั้ง / วันครบกำหนดบำรุงรักษา / วันหมดอายุ/ทดสอบแรงดัน | `2026-12-31` | **พิมพ์แบบ ค.ศ. ปี-เดือน-วัน** (หน้าเว็บแสดงเป็น พ.ศ. ให้เอง) |
| ใช้งานอยู่ | ☑ | ปลดระวาง = เอาติ๊กออก (อย่าลบแถว เพื่อเก็บประวัติ) |

> ห้ามสลับลำดับคอลัมน์ ระบบอ่านตามตำแหน่งคอลัมน์

### 7) พิมพ์ป้าย QR
เมนู **🧯 → 🖨️ เปิดหน้าพิมพ์ป้าย QR** (หรือในแอป: หน้าหลัก → 🖨️ พิมพ์ป้าย QR Code) → เข้าสู่ระบบด้วยบัญชี Admin → เลือกอาคาร → **พิมพ์**
- ตั้งค่าเครื่องพิมพ์: A4, Scale 100%, ปิด Headers/Footers
- ป้าย 5×6 ซม. แผ่นละ 12 ดวง แนะนำสติกเกอร์กันน้ำหรือเคลือบใส
- QR เป็นลิงก์ `WEBAPP_URL?id=FE-001` → สแกนด้วยกล้องมือถือธรรมดาได้ทันที

### 8) (ไม่บังคับ) สแกนกล้องสดบนมือถือ
หน้า Apps Script ทำงานในกรอบ (iframe) ของ Google ซึ่งมักไม่อนุญาตให้ใช้กล้องสด หน้าสแกนแยกใน `docs/index.html` เปิดกล้องได้เพราะอยู่นอกกรอบนั้น แล้วส่งต่อไปที่ลิงก์ของระบบ (รับเฉพาะลิงก์ `https://script.google.com/.../macros/s/.../exec`)
1. ผลักโฟลเดอร์ `docs/` ขึ้น GitHub แล้วเปิด **Settings → Pages → Source: Deploy from a branch → Branch: `main`, โฟลเดอร์ `/docs`** → Save
2. รอสักครู่ จะได้ URL เช่น `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`
3. วาง URL นั้นในชีต Config → `SCANNER_URL` (ถ้าไม่มีแถวนี้ ให้เพิ่มแถว: คอลัมน์ A = `SCANNER_URL`, คอลัมน์ B = URL)
4. **สำคัญ (ความปลอดภัย):** เปิด `docs/index.html` แล้วตั้งค่า `ALLOWED_APP_ID` เป็นรหัสในลิงก์ `/exec` ของระบบคุณ (ส่วนระหว่าง `/macros/s/` กับ `/exec`) แล้วผลักขึ้น GitHub ใหม่ — ถ้าปล่อยว่าง หน้าสแกนจะรับสคริปต์ของ Google ใดก็ได้ ซึ่งเปิดช่องให้ถูกหลอกกรอก PIN ในหน้าปลอม
5. Deploy ไฟล์ Apps Script เป็น New version ใหม่ — ปุ่ม **"เปิดตัวสแกนกล้องสด"** จะขึ้นในหน้าสแกนเมื่อกล้องในหน้านั้นเปิดไม่ได้

## สำรองข้อมูลและกู้คืน

- **อัตโนมัติ:** ทุกวันตี 2 ระบบคัดลอกทั้งไฟล์ Google Sheet ไปไว้ใน Drive โฟลเดอร์ "สำรองข้อมูล" (ชื่อไฟล์ `Backup_ปปปป-ดด-วว_ชชนน`) เก็บรายวัน 30 วัน + สำเนาล่าสุดของแต่ละเดือน 12 เดือน ส่วนที่เกินย้ายเข้าถังขยะ (กู้ได้ 30 วัน) ทุกครั้งที่สำรองจะเทียบจำนวนแถวของสำเนากับต้นฉบับ ถ้าไม่ตรงถือว่าล้มเหลว
- **ถ้าสำรองล้มเหลว** ระบบส่งอีเมลหา `ALERT_EMAILS` และถ้าไม่มีสำรองสำเร็จเกิน 48 ชั่วโมง อีเมลสรุปรายวันจะมีคำเตือน (ส่งแม้วันนั้นไม่มีถังชำรุด)
- **เมนู 💾 สำรองข้อมูลตอนนี้** สำรองด้วยมือ และระบบสำรองอัตโนมัติก่อน "ย้ายประวัติเก่า", "ล้างข้อมูลตัวอย่าง" และ "กู้คืนจากสำรอง"
- **เมนู ♻️ กู้คืนจากสำรอง** (เฉพาะเจ้าของระบบ) เลือกไฟล์สำรอง (15 ชุดล่าสุด) เลือกชีตที่จะกู้ (หรือ ALL) ระบบสำรองสภาพปัจจุบันไว้ก่อนแล้วจึงเขียนทับ รูปถังชำรุดไม่ถูก copy ซ้ำ เพราะเป็นไฟล์ใน Drive อยู่แล้ว
- **ห้ามแชร์โฟลเดอร์สำรองแบบลิงก์** เพราะมีชื่อผู้ใช้และข้อมูลการตรวจ
- **ย้ายไปโปรเจกต์ Apps Script ใหม่:** ค่าลับ (`TOKEN_SECRET`, `PIN_PEPPER`) อยู่ใน Script Properties ไม่ได้อยู่ในสำเนา PIN เดิมของทุกคนจะใช้ไม่ได้ ให้ตั้ง PIN ใหม่จากเมนู "ตั้ง PIN ใหม่ / ปลดล็อก"

## ทดลองระบบด้วยข้อมูลตัวอย่าง
1. เมนู **🧪 ใส่ข้อมูลตัวอย่าง** → ได้ถัง `DEMO-001`…`DEMO-010` และผู้ใช้ทดสอบ 2 คน (**PIN สุ่มให้ แสดงครั้งเดียว — จดไว้**)
   - มีถังปกติ, ชำรุดค้างจากเดือนก่อน, รอการตรวจ, หมดอายุ, ใกล้หมดอายุ ครบทุกแบบ
2. เปิด Web App บนมือถือแล้วลองตรวจ
3. เสร็จแล้วกด **🗑️ ล้างข้อมูลตัวอย่าง** (ลบเฉพาะข้อมูลที่ขึ้นต้นด้วย `DEMO-`)

## ทดสอบ logic
เมนู **✅ ทดสอบระบบ (runTests)** — ทดสอบการคำนวณสถานะ, เกณฑ์หมดอายุ, ลำดับชำรุด > รอตรวจ, ขอบเดือนตามเวลาไทย, hash PIN, token, การกัน formula injection และรายงานประจำเดือน (ไม่แตะข้อมูลจริง)

## การใช้งานของผู้ตรวจ
1. เปิดลิงก์ Web App (หรือสแกน QR บนถังด้วยกล้องมือถือ) → เลือกชื่อ + ใส่ PIN (จำการเข้าสู่ระบบ 12 ชั่วโมง)
2. **📷 สแกน QR Code** → ถ้ากล้องสดใช้ไม่ได้ กด **📸 ถ่ายรูป QR แทน** · QR ชำรุด → พิมพ์รหัสเอง (บันทึกเป็น MANUAL)
3. กด ✅ ผ่าน / ❌ ไม่ผ่าน ทีละข้อ → ถ้ามีข้อไม่ผ่าน ต้องถ่ายรูป → **💾 บันทึก**
4. ไม่มีสัญญาณ → ระบบเก็บผลไว้ในเครื่อง ("📤 รอส่ง") และส่งอัตโนมัติเมื่อกลับมาออนไลน์ **(เปิดหน้าเว็บค้างไว้)**

> เปิดลิงก์จาก LINE/Facebook แล้วกล้องไม่ทำงาน → แตะ ⋯ → **เปิดในเบราว์เซอร์** (Chrome/Safari)

## กติกาสถานะ
- **สถานะหลัก:** 🔴 ชำรุด > ⏳ รอการตรวจ > ✅ ปกติ
  - ผลตรวจล่าสุดไม่ผ่าน → **ชำรุด** (คงสถานะข้ามเดือน จนกว่าจะตรวจผ่าน)
  - ตรวจผ่านในเดือนปฏิทินนี้ → **ปกติ** · ยังไม่ตรวจเดือนนี้ → **รอการตรวจ**
  - ตรวจซ้ำได้เสมอ ใช้ผลล่าสุด (ตามเวลาที่ตรวจจริง แม้ส่งจากคิวออฟไลน์ภายหลัง)
- **ป้ายวันหมดอายุ** (แยกจากสถานะหลัก): ⛔ หมดอายุ = เลยวันครบกำหนดบำรุงรักษาหรือวันหมดอายุ · 🟠 ใกล้หมดอายุ = เหลือ ≤ `EXPIRY_WARN_DAYS` วัน
- **รายการตรวจ** แก้ได้ที่ชีต Checklist (คอลัมน์ "ใช้กับชนิด" ว่าง = ทุกชนิด เช่น ข้อเกจความดันไม่ใช้กับถัง CO2)

## ความปลอดภัย (สรุป)
- PIN เก็บเป็น SHA-256 วนซ้ำ 300 รอบ + salt ต่อผู้ใช้ + pepper ใน Script Properties — ไม่มี PIN จริงในชีต
- ใส่ PIN ผิด 5 ครั้ง → ล็อก 15 นาที
- Token ลงลายเซ็น HMAC-SHA256 อายุ 12 ชม. ผูกกับ PIN ปัจจุบัน; ทุก API ตรวจ token + role จากชีตทุกครั้ง
- ผลตรวจ (ผ่าน/ไม่ผ่าน) คำนวณฝั่ง server; รูปต้องเป็น JPEG จริง (ตรวจ magic bytes) ≤ ~3 MB
- กัน formula injection ในข้อความที่เขียนลงชีต, กันบันทึกซ้ำด้วย UUID, LockService กันเขียนชนกัน
- ฟังก์ชัน setup/เมนู/trigger เรียกจาก Web App ไม่ได้ (ตรวจว่าเป็นเจ้าของหรือ trigger จริง)
- รูปถังชำรุดเก็บใน Drive แบบ private ดูได้เฉพาะ Admin ผ่านแอป (server อนุญาตเฉพาะไฟล์ที่อ้างอิงในชีต Inspections)
- รายการ **ชื่อผู้ใช้** แสดงในหน้าเข้าสู่ระบบ (ไม่ใช่ความลับ) — ความปลอดภัยอยู่ที่ PIN จึงแนะนำ PIN 6 หลัก

## ข้อจำกัดที่ควรรู้
- **Real-time:** Apps Script ไม่รองรับ WebSocket → Dashboard ดึงข้อมูลใหม่ทุก 60 วินาที (server cache 30 วินาที และล้างทันทีเมื่อมีการบันทึก)
- **Gmail ส่วนตัวส่งอีเมลได้ ~100 ฉบับ/วัน** (Google Workspace ~1,500)
- **คิวออฟไลน์**เก็บใน localStorage ของเบราว์เซอร์: ต้องเปิดหน้าแอปไว้ตอนไม่มีสัญญาณ (เปิดลิงก์ใหม่ตอนออฟไลน์ไม่ได้), เวลาตรวจจากเครื่องยอมรับย้อนหลังไม่เกิน 7 วัน, Safari อาจล้างข้อมูลหากไม่ได้เปิดแอป 7 วัน
- เวลาส่ง trigger ของ Apps Script คลาดเคลื่อนได้ภายใน 1 ชั่วโมงที่กำหนด
- ขนาดที่ออกแบบไว้: ≤ 500 ถัง, ≤ 10 ผู้ตรวจพร้อมกัน, ประวัติหลายหมื่นแถว

## ทางเลือก: ใช้ clasp (สำหรับนักพัฒนา)
```bash
npm install -g @google/clasp
clasp login
```
เปิด Apps Script ของชีต → Project Settings → คัดลอก **Script ID** แล้ว
```bash
clasp clone <SCRIPT_ID>
```
คัดลอกไฟล์ทั้งหมดในโฟลเดอร์นี้ทับลงในโฟลเดอร์ที่ clone มา แล้ว
```bash
clasp push
```
จากนั้นทำขั้นตอน "ติดตั้งระบบ" ข้อ 2 เป็นต้นไป
