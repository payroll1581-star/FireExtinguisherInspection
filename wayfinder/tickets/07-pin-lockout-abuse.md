## Question

Five wrong PINs lock that user for 15 minutes, so anyone who opens the public link can lock any inspector out by name. Decide whether this trade-off is acceptable, or whether to change it (lock per device instead of per user, shorter or progressive locks, admin unlock from the menu, a notice to admin on repeated lockouts), keeping the priority that inspectors can always get in.
